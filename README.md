# 初中数学一年通关提升工作台 Pro 📐
> 基于北师大版初中数学知识体系的一站式提分工作台 · 考公级 10 题真题精练系统 · 权威微课名师沉浸式电子黑板

---

## 🌟 项目亮点与核心功能

1. **🗺️ 六大核心板块知识树全景**
   - 涵盖【数与代数】、【方程不等式】、【函数与图像】、【几何基础】、【几何综合与圆】、【统计与概率】全考点。
   - 支持考点掌握状态打卡（⚪未学 ⏳攻坚中 ✓已吃透 ✕需二刷）与总体通关进度环形/条形图统计。

2. **✏️ 考公 / 粉笔 APP 级 10 题真题刷题系统**
   - **阶梯式真题训练**：每个考点严格配备 10 道中考经典真题（基础巩固 3 题 + 综合拔高 4 题 + 中考压轴 3 题）。
   - **沉浸式刷题交互**：具备做题秒表计时 ⏱️、1-10 题答题卡抽屉（随时跳题）、大卡片单题沉浸选项、即时判分与错题自动秒收录。
   - **粉笔式四维深度解析**：涵盖【🎯 考点定位】+【💡 秒杀技巧】+【📝 规范步骤】+【⚠️ 易错警示】。
   - **中考成绩单诊断**：10 题答完交卷后自动生成得分率圆环、用时统计与同龄考生击败率。

3. **📺 名师沉浸式电子黑板微课系统**
   - 彻底避免外部防盗链黑屏，采用本地高质感名师电子黑板。
   - 配备【第 1 讲·核心概念与定理推导】、【第 2 讲·中考必刷题与典型例题】、【第 3 讲·易错陷阱与满分秒杀套路】多选集秒级无缝切换。
   - 提供国家中小学智慧教育平台与洋葱动画微课官方直达通道。

4. **❌ 错题攻坚本与数据持久化**
   - 错题一键收录与重做攻克；
   - 支持本地存储（LocalStorage）、学习进度 JSON 一键导出与跨设备导入、A4 复习单专属打印。

## 📂 项目结构

```text
├── 初中数学一年通关工作台.html   # 主应用（双击即可直接在浏览器运行）
├── math_data.js                 # 预载入前端数据源（包含 33+ 核心考点 10 题真题库与讲义）
├── math_data.json               # 结构化题库与微课 JSON 数据
├── crawler/                     # 数据抓取与题库生成引擎
│   ├── bilibili_video_crawler.py  # 名师微课与板书生成器
│   ├── seed_question_bank.py      # 10 题阶梯真题与四维深度解析生成器
│   ├── export_data.py             # 数据整合与一键导出工具
│   └── question_crawler.py        # 试卷网与外部题库抓取接口
└── .gitignore                   # Git 忽略配置
```

## 🚀 快速开始

### 1. 本地使用
无需安装任何复杂环境，直接在文件管理器中双击打开 **`初中数学一年通关工作台.html`** 即可在任意浏览器中完整使用！

### 2. 更新题库或微课数据
如需重新生成或扩充题库数据，在项目根目录下运行：
```bash
python crawler/export_data.py
```

## 🌐 开启 GitHub Pages 在线免安装访问

您可以非常简单地开启 GitHub Pages，让手机、平板或电脑直接在线访问：
1. 打开您的 GitHub 仓库：[junior-math-workbench](https://github.com/MrZh2025/junior-math-workbench)；
2. 点击 **Settings** ➡️ 左侧菜单 **Pages**；
3. 在 **Branch** 下选择 `main` 分支，目录选择 `/ (root)`，点击 **Save**；
4. 等待 1-2 分钟，即可获得专属的在线网页链接直接刷题学习！
